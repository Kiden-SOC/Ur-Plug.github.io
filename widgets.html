App Design Components

We built our Ur Plug interfaces using custom reusable components in Flutter. This helps make our signup sheets, chat interfaces, and buttons look matching and professional on every screen.

Custom Input Fields

This component is used whenever a user needs to type into the application. It provides uniform borders and placeholder hints for fields like phone numbers, emails, and district names.

How it works: It ensures that the text boxes on our Customer Signup, Business Signup, and Login screens look exactly the same before checking if the user filled out the fields properly.

Provider Profile Blocks

This is the layout box used when the search results page matches a user's typed keyword against available service providers in the Firebase database.

How it works: It displays the provider's business name, listed skills, their location, and their ratings clearly in a compact card template so consumers can quickly pick someone reliable.

In-App Chat Elements

This component creates individual chat counts inside our integrated message setup. It keeps count of the number of messages received and haven't yet been opened.

How it works: It helps customers and providers chat back and forth in real-time to discuss project scope, urgency, and agree on prices before committing to any service requests.
